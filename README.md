# WIT Community Website 💜

A website prototype for the **Women in Tech (WIT)** community under TinkerHub Foundation.

This project aims to create a space where women can connect, learn, collaborate and explore opportunities in technology.

## ✨ Features

- About the WIT community
- Events and learning opportunities
- Community stories and initiatives
- Ways to get involved
- Interactive polls and feedback
- Beginner-friendly open source contribution guide
- Responsive design

## 🛠️ Built With

- React
- Vite
- JavaScript
- CSS

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/rrinuiee/wit-website.git
```

Install dependencies:

```bash
cd wit-website
npm install
```

Run the website:

```bash
npm run dev
```
